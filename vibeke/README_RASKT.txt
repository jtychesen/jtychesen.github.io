VIBEKE-SIDEN – RASKT OPP PÅ GITHUB PAGES

Dette ligger i pakken:
- index.html
- assets/terrasse.png
- assets/karmoy_aerial.png

SLIK LEGGER DU DEN UT PÅ joakimtychesen.dev/vibeke/

1. Åpne repo-mappen for nettsiden din.
2. Lag en mappe som heter:
   vibeke
3. Legg index.html inni vibeke/
4. Legg assets-mappen inni vibeke/

Strukturen skal bli:

vibeke/
  index.html
  assets/
    terrasse.png
    karmoy_aerial.png

Hvis repoet ditt allerede er koblet til joakimtychesen.dev:

- kopier vibeke-mappen inn i repoet
- commit
- push

Terminal-eksempel:

cd "/Users/mbp127jt/0_mbp127_icloud/DEV/Website_portfolio"
git add vibeke
git commit -m "Add Vibeke surprise page"
git push

Når push er ferdig, åpne:
https://joakimtychesen.dev/vibeke/

Hvis du heller vil gjøre det direkte på GitHub:

1. Gå inn i repoet på github.com
2. Trykk Add file -> Upload files
3. Dra inn hele vibeke-mappen (eller lag mappen og last opp filene inni)
4. Commit changes
5. Vent litt
6. Åpne joakimtychesen.dev/vibeke/
